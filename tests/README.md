# Test Suite

- `packages/shared/test/`: Zod schema and contract validation tests
- `apps/worker/test/`: RBAC/ownership policy, workflow transition, and R2 storage validation tests
- `apps/web/src/**/*.test.tsx`: React component tests
- `tests/e2e/`: End-to-end report lifecycle verification

Run all tests from repository root:

```bash
npm test
```
